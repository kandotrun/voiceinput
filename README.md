# voiceinput

Aqua Voice の代替として作る、Kan 専用の Mac 音声入力アプリ。

既存の個人文字起こしエンドポイント（Mac 上で常駐する Qwen3-ASR-1.7B ＋ 個人辞書補正）を使い、どのアプリでも **右 Option（Right Alt）キー** で音声入力できるようにする。

## 操作

- **長押し（プッシュトゥトーク）**: 右 Option を押している間だけ録音し、離すと文字起こししてカーソル位置へ挿入
- **ダブルプレス（ハンズフリー）**: 右 Option を2回素早く押すと録音を継続し、もう1回押すと停止して挿入

## 設計

詳細は [docs/SPEC.md](docs/SPEC.md)。要点:

- Swift 製メニューバー常駐アプリ（AppKit / SwiftUI 設定画面）
- キー監視は CGEventTap で右 Option（keycode 61）の flagsChanged を見る。録音中に他のキーが押されたら修飾キーコンビネーションとみなしてキャンセル
- 録音は AVAudioEngine、16kHz モノラルで一時ファイルへ
- 文字起こしは既存エンドポイント `POST /transcribe`（Mac の `~/transcribe-endpoint/`、Tailscale IP:8791、Bearer 認証）へ送信。トークンはリポジトリに入れず、アプリ設定 / ローカルファイルから読む
- 挿入はクリップボード経由＋ Cmd+V シミュレーション（元のクリップボードは復元する）。要アクセシビリティ権限
- 短い発話ではレイテンシ優先のため、LLM 補正（correct）の ON/OFF を設定可能にする

## 必要な権限

- マイク
- アクセシビリティ（キー監視と貼り付け）
- 入力監視（Input Monitoring）が必要になる場合はその案内も出す

## 状態

v1実装済み。XcodeのDebug / Releaseビルドと自動テストを確認。実機のキー操作・権限・発話レイテンシは確認待ち。

## ビルド・起動

macOS 13以降、Xcodeが必要です。外部パッケージ依存はありません。

```sh
xcodebuild -project VoiceInput.xcodeproj -scheme voiceinput \
  -configuration Release -derivedDataPath build build
open build/Build/Products/Release/voiceinput.app
```

`VoiceInput.xcodeproj` をXcodeで開いて実行することもできます。ローカル実行用のアドホック署名を使います。継続利用する場合は生成した `.app` を `/Applications` 等の固定場所にコピーし、その場所のアプリへ権限を付与してください。配布・公証は含みません。

メニューバーのマイク →「設定・再試行用音声…」から設定します。マイク・アクセシビリティを許可し、必要なら入力監視も許可して「権限を再確認・キー監視を再接続」を押してください。macOSから再起動を求められた場合はアプリを再起動してください。「ログイン時に起動する」は固定場所へ移動してから有効にします。

- トークンは既定で `~/transcribe-endpoint/.env` の `TRANSCRIBE_TOKEN` を読みます。設定の上書き値はmacOSキーチェーンに保存し、空欄を保存すると既定へ戻ります。秘密情報をUserDefaultsやログに出力しません。
- URLはベースURLを指定します（既定 `http://100.72.208.31:8791`）。補正は実測前の暫定値として **OFF**。5秒・15秒・60秒のON/OFF比較後に日常利用の設定を決めてください。
- 最初の短押しは録音を破棄して2回目を待ちます。押下開始から350ms以内の2回目も短押しならハンズフリー、2回目を長押しすると通常のプッシュトゥトークです。別キーとの組み合わせやEscでは破棄します。監視は入力を抑止しないので、Optionとの通常入力は対象アプリへ届きます。
- 音声は16kHz・モノラルFloat32 WAV。0.3秒未満、またはRMSが0.003未満の音声は破棄します。小声・騒音環境での閾値調整は実地確認後に判断してください。
- 失敗音声・アプリ強制終了時の音声は `~/Library/Application Support/voiceinput/再試行用音声/` に残ります（ディレクトリ0700、ファイル0600）。設定から再試行すると結果をコピーします。対象アプリへ手動で貼り付けてください。通知が未許可でも設定画面にエラーを表示します。
- 成功後はWAVを削除します。文字起こし結果の `.txt` は同じ保存場所へ保持します。Cmd+Vを送れた場合でも対象アプリでの受理は判定できないため、挿入できなかった場合の回収に使えます。不要になった音声・テキストはFinderから削除してください。
- 通信中の新しい録音は開始しません。録音開始時のアプリを挿入先として保持し、結果が返った際にそのアプリをアクティブにします。再試行では自動挿入しません。
- クリップボード復元は送信後500ms待ちます。その間に別のコピー操作があった場合は復元しません。貼り付け処理が遅いアプリでは復元OFFも試してください。

## 自動検証

```sh
python3 Tests/run.py
```

Swiftコンパイラでキー状態機械を検証し、ローカルのHTTPフィクスチャへダミートークンで通信します。実際のトークン・ASR・マイク・クリップボードは使用しません。

GUI確認項目と実測表は [docs/VALIDATION.md](docs/VALIDATION.md) にまとめています。
