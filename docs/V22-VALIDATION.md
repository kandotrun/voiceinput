# v2.2 精度改善とリポジトリ管理化（2026-11-04）

## 背景と稼働状態

Kanが日常利用で「絶妙に誤字が残る」と感じたため、文字起こしエンドポイントの補正経路を見直した。変更は Mac の `~/transcribe-endpoint/` へ直接実装・稼働反映済み（`app.py` のバージョン表記は 2.2.0）。voiceinput アプリの変更はない。

あわせて、本PRからエンドポイントのコードもこのリポジトリ（`endpoint/`）で管理する。v2.1 までの「エンドポイントのコード・設定・キャッシュ・音声はこのリポジトリへ含めない」方針は、Kanの指示により変更する。含めるのはコード・静的辞書・テスト・運用文書のみで、`.env`（トークン・設定値）、`dynamic_terms.json`（自動生成キャッシュ）、ログ、音声は含めない。

見直しで特定した誤りの原因:

1. 補正プロンプトが「辞書にある固有名詞の置換のみ」を許可し、一般語の誤変換（同音異義語など）は設計上素通りしていた。
2. 静的辞書が19語のままで、現在の語彙（TransAI、髙松、羅針盤など）が入っていなかった。動的辞書キャッシュの再生成も Hindsight recall の間欠失敗で止まることがあった。
3. Qwen3-ASR の癖のある誤認（羅針盤→「ラッシュ版」など）は音の距離が大きく、LLM 補正でも届かなかった。

## 変更内容

変更: `app.py`、`dynamic_dictionary.py`、`terms.txt`、`tests/test_hindsight.py`、`tests/test_dynamic_dictionary.py`、`README.md`。

1. **補正範囲の拡張**: プロンプトを「固有名詞の置換」と「文脈上明らかな誤変換の最小修正」の2種に変更。言い換え、語尾・口調の変更、内容の追加・削除は引き続き禁止。
2. **受理ガードの変更**: 従来の置換限定ガード（`replacement_only`）に加え、ハンク単位ガードを追加。全体の類似度 0.85 以上を要求し、各編集ハンクが「辞書語の一部への置換」か「2文字以内の小修正」のどちらかである場合だけ受理する。人名をフルネームへ展開する挿入（例: 森川さん→森川拓真さん、有馬さん→有馬惟住さん）は明示的に拒否する。複数の辞書置換が1セグメントに集まっても合計編集距離で弾かない。
3. **決定的置換の導入**: LLM 補正の前に規則で置換する。LLM が失敗した場合もこの置換結果は残る。

   | 誤認 | 正 |
   |---|---|
   | ラッシュ版 / ラジン版 | 羅針盤 |
   | ギットハブ | GitHub |
   | クロードコード | Claude Code |
   | トランスエーアイ / トランスエイアイ | TransAI |

4. **静的辞書の拡張**: 19語→25語（羅針盤、TransAI、髙松、Sono、GitHub、Claude Code を追加）。主要語には読み（羅針盤=ラシンバン等）を付与し、動的辞書の読みと合わせてプロンプトへ渡す。フルネーム（有馬惟住、髙松築）は展開事故を避けるため入れず、姓のみ（髙松）とした。
5. **動的キャッシュ読み込みの堅牢化**: 静的辞書へ昇格した語がキャッシュに残っていても、検証時の重複排除でキャッシュ全体を無効化しないよう変更した（従来は件数不一致で全件破棄されていた）。
6. **不採用**: ASR（Qwen3-ASR）の `context` 引数へ辞書を渡すバイアスは、ベンチ音声で A/B 実測したが改善がなかった（5秒音声は「ラジン版」→「ラッシュ版」と変化しただけで不正解のまま）。リスクだけが残るため入れていない。

テストの更新（仕様変更に伴うもの）:

- `test_fallback_prompt_matches_v1_exactly` は v2 の不変条件「フォールバック時は v1 プロンプトとバイト一致」を検証するものだったが、v2.2 でベースプロンプト自体を変更したため、`test_fallback_prompt_is_v22_base`（v2.2 ベースプロンプトの内容と記憶セクション非混入を検証）へ置き換えた。
- `test_cache_and_off_modes_do_not_recall` のマーカー語は、羅針盤が静的辞書へ昇格して常時含まれるようになったため、動的専用の Mapbox へ変更した。

### 実 API（稼働中サービスへ送信、correct=true）

ベンチ音声は v2.1 検証で使った実音声、TTS は macOS Kyoko の say で生成した16kHz mono WAV。

| 音声 | ASR 生出力 | v2.2 出力 |
|---|---|---|
| ベンチ5秒 | ラジン版の森川さんに連絡しておいて。 | 羅針盤の森川さんに連絡しておいて。 |
| ベンチ15秒 | ラッシュ版の森川さんに連絡しておいて、… | 羅針盤の森川さんに連絡しておいて、…（全文正） |
| ベンチ Mapbox | マップボックスで広島の地図を作ってください。 | Mapboxで広島の地図を作ってください。 |
| TTS: TransAI 面談 | トランスAIの有馬さんと高松さんに明日の面談の資料を送ってください。 | TransAIの有馬さんと髙松さんに明日の面談の資料を送ってください。 |

| TTS: 一般文（対照） | この件は意外と時間がかかりそうです。後で確認して返信します。 | （無変更） |

## 残課題

- 音の距離が大きい未知の誤認は、決定的置換に登録した語以外は LLM 補正の限界が残る。実利用で見つけた誤字は、文ごと記録して辞書・置換ルールへ追加していく。
- 動的キャッシュ再生成の Hindsight recall 間欠失敗は未解決（キャッシュ保持と自動リトライで実害は抑止できている）。
